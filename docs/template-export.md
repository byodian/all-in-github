# 公开博客模板导出

当前仓库包含个人博客内容，不应直接作为公开模板仓库分发。导出器从固定的 AstroPaper 官方版本中按白名单复制通用主题源码，生成一个位于当前仓库之外的新目录，并初始化全新的 Git 历史。

## 导出模板

需要 Node.js 和 Git。先确保目标目录不存在，再从项目根目录运行：

```sh
npm run template:export -- --destination ../astro-blog-template
```

导出器会从官方 AstroPaper 仓库检出固定标签和提交，验证来源后生成模板。Git 会使用当前项目中配置的用户身份创建唯一的初始提交。目标目录已存在或位于当前项目内时，导出会被拒绝，不会覆盖内容。

## 安全边界

- 按 `scripts/template-theme-files.json` 中的逐文件清单复制主题配置、锁文件、页面、布局、组件、样式、工具、图标和指定主题图片；新增上游文件不会自动进入模板。
- 不复制原个人文章、About 页面、个人图片、工作流、Issue 或 Git 历史；生成通用 About 页面和空文章目录。
- 保留当前项目及 AstroPaper 各自需要的许可证，并在新项目中记录上游来源与固定提交。
- 本地集成测试通过显式传入合成主题仓库验证导出流程；正常命令不接受替代主题来源，且会校验 AstroPaper 固定提交。

验证导出器：

```sh
npm run test:template-export
```

导出的基础阶段尚不包含最终浏览器配置向导、初始化和发布流程，完成后续实施阶段之前不应将其作为最终模板产品发布。
