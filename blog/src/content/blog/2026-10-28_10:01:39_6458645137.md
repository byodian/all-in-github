## 安装 uv

使用 [uv](https://github.com/astral-sh/uv) 管理 python 依赖和虚拟环境

```bash
# On macOS and Linux.
curl -LsSf https://astral.sh/uv/install.sh | sh

# On Windows (PowerShell).
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

## 安装 python 依赖

```bash
# 创建虚拟环境
uv venv

# 激活虚拟环境
source .venv/bin/activate  # Linux / macOS
.venv\Scripts\activate     # Windows

# 安装单个包
uv pip install numpy

# 安装依赖，使用腾讯镜像源加速
uv pip install -r requirements.txt --index-url https://mirrors.tencent.com/pypi/simple

# 导出依赖
uv pip freeze > requirements.txt
```

## 运行脚本

每个环境都必须有对应的环境变量配置文件 `.{env}.env`，例如 `.env.dev`、`.env.test`、`.env.prod`。

```bash
uv run export_influxdb.py --env dev
uv run export_influxdb.py --env test
uv run export_influxdb.py --env prod
```
